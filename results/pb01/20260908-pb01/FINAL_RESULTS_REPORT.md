# PB01 正式实验报告：码义复用屏障桥接实验

运行日期：2026-09-08  
状态：完成；预注册总判定未通过（7 项门槛通过 6 项）

## 1. 总结

PB01 在共享参数的两层神经 receiver 中稳定复现了码义复用屏障：30/30 个种子均满足 `C0_CE<0<C2_CE`，空闲第四消息将即时屏障降低约 100%，随机和无信息改写均不能复现收益。

但是，预注册要求 D 相对 C 在 `T=2` 时准确率至少提高 10 个百分点。该项中位数为 0，因此 PB01 不能判定为完整通过。

结果支持：

> 连续训练损失层面的信用成熟和槽位复用机制已经跨越表格模型，在参数共享神经 receiver 中复现。

尚未按预注册支持：

> 在同一个 `T=2` 预算内，成熟信用已经转化为离散决策准确率提升。

## 2. 最小性消融

| 消融 | P1 | 跨 `α=0.25/0.5` 稳健 P1 | P2 屏障 | 解释 |
|---|---:|---:|---:|---|
| A1：4 状态、3 消息、3 类 | 0 | 0 | 0 | `2+1+1` 分区下，非充分状态必然并列；5 状态是当前无并列反例的最小规模 |
| A2：5 状态、3 消息、2 类 | 60 | 60 | 0 | 可有直接信用成熟，但存在绕行路径 |
| A3：5 状态、2 消息、3 类 | 120 | 0 | 120 | 仅在 `α=0.5` 成立，且真正使用 3 类的任务不可解 |
| A4：增加空闲第四消息 | — | — | 屏障消失 | 两种平滑下即时信用均从负值变为 0 |

因此，“三类别”不是直接 P1 的绝对必要条件，但稳健、不可绕行的 P2 屏障需要当前测试到的组合：至少 5 个状态、全部消息槽位被占用、重复旧码义以及尚未独立表示的新类别。

## 3. 神经桥接设置

- sender 编码由硬离散干预固定；
- receiver 为 `one-hot message → 8维 tanh → 3类 softmax`；
- receiver 参数在不同消息之间共享；
- 通过软目标预训练恢复 R3 当前码义；
- 30 个随机初始化种子；
- 全批量 SGD 适配；
- 主预算 `T=2`，记录至 32 步；
- 预训练条件概率最大误差中位数为 `2.96e-7`。

## 6. 事后时间诊断

以下分析在看到 `T=2` 准确率失败后进行，不计入本轮通过判定：

| 步数 | D−C 准确率中位数 | 达到至少 10pp 的种子 |
|---:|---:|---:|
| 0 | 0 | 0/30 |
| 1 | 0 | 0/30 |
| 2 | 0 | 2/30 |
| 4 | +0.2 | 30/30 |
| 8–32 | +0.2 | 30/30 |

这揭示了两个不同时间尺度：

- `T_loss=2`：概率分布意义上的信用成熟；
- `T_decision=4`：argmax 决策跃迁。

本轮不能事后把主预算改成 4；该发现只能用于设计全新确认实验。
