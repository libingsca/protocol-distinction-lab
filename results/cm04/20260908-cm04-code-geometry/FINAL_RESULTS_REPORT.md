## 冻结设计与执行范围

- 完整均衡训练表 512 行：q=0,1、V=0..15、r=0..15，答案 y=(V+r) mod16；顺序为 q、V、r 升序。
- E0 为 m=V；E1/E2/E3 分别来自 NumPy PCG64 seeds 84001/84002/84003 的首次 permutation(16)，两个 q 共用同一映射。不筛选、不重抽。
- 四种编码各占用全部 16 条消息，各 q 下每条消息出现 16 次；精确计数得到 H(M|q)=I(V;M|q)=4 bit。符号逆映射 decoder 对全表均 100% 正确，仅用于可解性检查。
- 新初始化 seeds 60..89，30 个；每种子按标准 Linear/ReLU 顺序生成一个 22→64→64→4 MLP，所有分支从其复制。
- bit 表示输入为消息四位与四零、固定八维 mask、q 两维 one-hot、r 四位。one-hot 表示输入为消息 16 维 one-hot、q 两维 one-hot、r 四位，参数数目相同。
- one-hot 的随机编码分支配对置换首层前 16 列，满足 W_k[:,pi_k(V)]=W_0[:,V]；其余参数不变。这是显式参数控制，不是学得逆映射。
- 每分支 Adam 从空状态重置：lr=0.001、betas=(0.9,0.999)、eps=1e-8、weight_decay=0；无调度、裁剪或额外训练。
- 每步使用全部 512 行，四位 BCE 均值；100 个全批次更新。两种表示×四种编码×30 种子，共 240 分支、24,000 次更新。
- 所有编码、输入表和 30 个原始初始化在第一次更新前锁定。没有加载历史 checkpoint 或历史训练/验证/测试标签。

| 控制量 | 全部配对最大值 | 冻结上限 |
|---|---:|---:|
| 0..100 步 BCE 差 | 0 | 1e-5 |
| 0..100 步准确率差 | 0 | 1e-5 |
| 初始 logits 差 | 0 | 1e-4 |
| 最终 logits 差 | 0 | 1e-4 |

这验证了在显式配对输入列权重后，单纯消息重命名没有制造比较差异。不能把控制的等价性称为神经模型自主学会了编码变换；它也不证明所有表示都具有相同学习难度。
