# PB02：码义复用屏障的双时间尺度独立确认

## 1. 研究问题

PB01 表明交叉熵在第 2 步成熟，而准确率在第 4 步跃迁。PB02 使用未参与 PB01 的新种子验证：

> 码义复用是否稳定表现为“损失信用先成熟、离散决策后跃迁”的双时间尺度过程？

## 2. 冻结设置

- 使用种子 `30–59`，与 PB01 的 `0–29` 完全隔离；
- 网络、初始化分布、预训练步骤和学习率保持不变；
- 任务保持 `y=(0,1,2,0,1)`；
- 当前协议保持 `S=(0,1,1,2,1)`；
- 目标协议保持 `S'=(0,1,2,0,1)`；
- `T_loss=2`；
- `T_decision=4`；
- 不再根据结果修改这两个时间点。

## 3. 主要判据

PB02 只有全部满足才通过：

1. 至少 24/30 个新种子满足 `C0_CE<0<C2_CE`；
2. `C0_CE` 中位数 ≤ -0.05；
3. `C2_CE` 中位数 ≥ +0.02；
4. 至少 24/30 个种子在 `T=4` 满足 D−C 准确率 ≥ 0.10；
5. `T=4` 的 D−C 准确率中位数 ≥ 0.10；
6. 空闲第四消息的即时屏障下降中位数 ≥ 50%；
7. 目标改写的 `C2` 高于同距离随机改写和无信息改写。

## 4. 次要结构检查

- 报告每个种子的首次交叉熵转正时间与首次准确率跃迁时间；
- 检验二者是否满足 `t_loss<t_decision`；
- 额外运行隐藏层宽度 4 和 16，但只作为架构稳健性，不改变主判定；
- 直接线性 receiver 作为表格极限对照；
- 软消息路径继续记录，但不作为通过门槛。

## 5. 结果分流

| 结果 | 下一步 |
|---|---|
| PB02 全部通过 | 启动六个 J-GROUP16 历史模型的 CM01-RP“重复码义诊断” |
| 损失复现、准确率再次失败 | 将机制限定为概率校准层，不进入历史准确率实验 |
| 空闲码不再消除屏障 | PB01 因果解释不稳定，回到表示耦合机制 |
| 新种子不能复现 `C0<0<C2` | PB01 属于初始化条件效应，停止外推 |

## 6. 历史模型接口

PB02 通过后，对六个 J-GROUP16 checkpoint 先做只读诊断：计算 16 个消息在 receiver 不同 `q,r` 条件下的响应距离，寻找“多个消息近似同义、必要 `V` 类别未独立表示”的码义占用结构。只有检测到该结构的模型才进入 A/B/C/D 改写实验。
