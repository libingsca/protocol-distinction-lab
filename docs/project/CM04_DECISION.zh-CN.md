# CM04 分流决策

日期：2026-09-08。run_id：`20260908-cm04-code-geometry`。
依据：[正式报告](../../results/cm04/20260908-cm04-code-geometry/FINAL_RESULTS_REPORT.md)。

## 决定：规划 CM05 训练反馈选择诊断，未执行

CM04 按冻结计划完成 240 分支、24,000 次全批次更新，独立算法审计通过。三个固定随机编码 E1/E2/E3 的联合主判据达标数为 28/30、24/30、25/30，全部满足每种编码至少 24/30 的门槛。
全部 90 个 one-hot 配对对照通过；每步 BCE/准确率差和初末 logits 差均为 0。该等价性来自明确披露的配对参数置换，不是模型自主发现映射。

结果支持：在平衡任务、bit 表示、新初始化与 100 步预算下，预先指定的数值对齐编码比本轮三个随机双射具有相对可学习性优势。该差异不需要历史 checkpoint 偏好才能出现。
bit E0 的准确率中位数仅 0.341797（范围 0.292969–0.505859），所以本轮没有学成充分解码，更没有解决自主协议形成。

下一步问题从“预先给定的编码是否更易学”转为“任务损失能否在未给定好编码时帮助选择”：规划 [CM05](../experiment-plans/cm05-feedback-selection.zh-CN.md)，新 run_id `20260908-cm05-feedback-selection`。只使用预生成候选池与通用训练损失排序，用不参与排序的新初始化检验选择收益。
候选双射支架仍外部保证信息充分，全训练表用于评分；必须称为受约束搜索/选择诊断，不能称为自主协议形成。主判据、输入、对照、预算及失败停止条件已另立计划；本轮不执行 CM05。

## 保留失败与结论边界

- E1 的 2 个、E2 的 6 个、E3 的 5 个种子未达到联合门槛；全部保留。三个比较的 90/90 损失差都达标，未通过项来自准确率增益不足。E2 恰好达到 24/30，不改写为更强稳健性。
- 不比较 bit 与 one-hot 的绝对性能来宣称单因素架构收益：二者输入布局不同，one-hot 又有配对参数控制。
- 三种置换、一个任务族和全表训练域不等于所有协议或测试泛化。种子配对反映初始化变化，不当作独立任务确认。
- CM03 当前候选/预算下的信用成熟迁移失败保持不变；新初始化的 CM04 阳性不能把它追认成训练不够久或主判据选错。
- CM02 静态结构结论与 PB02 玩具任务结果保留；CM01-RP 原分支继续终止。

## 停止与再评估边界

CM04 这轮固定编码比较已完成，不追加随机置换、种子、训练步数或历史模型。继续工作仅限新 CM05 已定义的问题；若其主判据失败，按新计划停止，不倒回 CM04 调宽门槛维持阳性。
